# Digital IIR Filter — MATLAB → VHDL → FPGA (Cyclone V)

A 5th-order elliptic low-pass IIR filter, taken from MATLAB/Simulink design
through fixed-point VHDL to FPGA synthesis. Built to isolate rotating shaft
motion signals from bearing-fault noise in an industrial monitoring
application.

## Design Requirements

| Requirement | Value |
|---|---|
| Filter type | Low-pass IIR |
| Sampling frequency | 48 kHz |
| Passband ripple | < 0.1 dB |
| Stopband attenuation | > 40 dB |
| Desired signal | Rotating shaft motion, 50 Hz – 1.5 kHz, ±3 dBV |
| Noise | Broadband + sinusoidal interference, 2.5 kHz – 6 kHz, –5 to +10 dB (ref. 1V RMS) |
| Sampling duration | 1 second |

Elliptic design was chosen for its sharp roll-off, meeting both ripple and
attenuation specs at low filter order.

## Design

Three cascaded Direct Form II Transposed biquad sections, generated by HDL
Coder from the Simulink fixed-point model in Q1.14 (16-bit, 14 fractional
bits).

![RTL block diagram](synthesis/quartus_rtl_viewer.png)

*Quartus RTL Viewer: synthesized hierarchy matches the design — 3 biquad sections cascaded via `dataOut → dataIn`, gated by `validOut/validIn`.*

## Tools

VHDL · MATLAB & Simulink (HDL Coder) · AMD Xilinx Vivado · Intel Quartus Prime

## Simulation

`Filter_Processing1_tb.vhd` is self-checking: drives clock/reset/input,
compares each output sample against a reference value every cycle, and
prints `TEST COMPLETED (PASSED/FAILED)`.

## Synthesis & Implementation

Cross-checked on Vivado (Kintex UltraScale, power/timing) and Quartus
(Cyclone V target):

![Vivado implementation summary](synthesis/vivado_implementation_summary.png)

- Timing: WNS 2.898 ns, 0 failing endpoints of 673
- Utilization: LUT/LUTRAM/FF/DSP ≤1%, IO 7%
- Power: 0.746 W (98% static — expected for a small design on a large device)

![Quartus resource summary](synthesis/quartus_resource_summary.png)

- Cyclone V: 544 registers, 7 DSP blocks, 22 pins, 120 memory bits
- ALM utilization not captured (requires full Fitter compilation)

## FPGA I/O Mapping

`constraints/fpcoms.xdc` targets a Xilinx KCU105 board: 100 MHz clock,
reset/clock-enable to push-button/switch, `In1` to DIP switches, `Out1` to
LEDs.
