# digital-iir-filter-matlab-vhdl-fpga
5th-order elliptic low-pass IIR filter: MATLAB/Simulink golden reference → fixed-point VHDL (cascaded biquad/SOS) → FPGA implementation. Synthesized and analyzed in Vivado (power, timing, utilization) and Quartus Prime (RTL viewer, chip planner) targeting Cyclone V.
